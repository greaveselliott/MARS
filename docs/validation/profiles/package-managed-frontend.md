# Habit Tracker Demo

Build a small habit tracker web app using Vite and React.

The app should be a package-managed project with a `package.json`, npm dependencies, and working `dev` and `build` scripts. It should let a user add a habit with a name and target days per week, list habits, mark a habit done for today, and show a simple weekly completion summary per habit. State can live in browser local storage. The UI should be clean and usable in a desktop browser via the Vite dev server.
