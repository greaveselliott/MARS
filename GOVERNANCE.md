# MARS Governance

MARS is currently maintained by Elliott Greaves (`@greaveselliott`). The
maintainer owns releases, security response, roadmap decisions, repository
settings, and final merge decisions.

Contributions arrive through fork pull requests. Required automated checks,
DCO sign-off, CODEOWNERS review, and the policies in this repository apply to
every contribution. The maintainer may request changes or decline work that
does not fit the product direction, safety boundaries, or maintenance budget.

MARS uses a trunk-based maintainer workflow. The protected-branch ruleset has
an explicit repository-administrator bypass so the maintainer can land
reviewed, validated checkpoints directly on `main`; contributors cannot use
that bypass. Force pushes and branch deletion remain prohibited by the
ruleset for ordinary contributors.

Material changes to governance will be committed and reviewed like other
public-contract changes. Additional maintainers may be added only through an
explicit recorded decision and least-privilege repository access.
