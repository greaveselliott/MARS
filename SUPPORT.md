# MARS Support

- Use [GitHub Discussions](https://github.com/greaveselliott/MARS/discussions)
  for setup questions, usage help, and design discussion.
- Use the repository issue forms for reproducible defects and bounded feature
  proposals.
- Use [SECURITY.md](SECURITY.md) for suspected vulnerabilities; never disclose
  them in an issue or Discussion.

MARS is maintained on a best-effort basis. Include the MARS version or commit,
platform, relevant non-sensitive configuration, expected result, and safe
reproduction steps. Remove credentials, private source, raw model prompts,
and sensitive logs before posting.
